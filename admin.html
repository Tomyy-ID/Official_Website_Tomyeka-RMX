Ajukan perubahan konfigurasi / file

Isi konten lalu buat Issue. Kamu harus masuk ke akun GitHub untuk mengirim pengajuan. Perubahan belum diterapkan sampai pemilik repository memberi label admin-approved.

Batas upload melalui form: 8 KB per file. Untuk file lebih besar, gunakan halaman upload GitHub secara langsung.

Upload file besar / kelola file langsung

Untuk file gambar, audio, atau video berukuran besar, gunakan GitHub web. Setelah login GitHub, unggah ke folder assets/ dan buat commit di branch main.

Catatan keamanan penting
  • Halaman GitHub Pages bersifat publik; halaman ini bukan sistem autentikasi privat.
  • Tidak ada token atau secret GitHub yang disimpan di browser.
  • Workflow hanya memproses Issue jika label admin-approved ditambahkan oleh pemilik repository tomyy-id.
  • Workflow hanya mengizinkan perubahan ke pengaturan-data.js atau file yang diizinkan di folder assets/.
