Tujuan

Menyediakan tempat yang rapi untuk mengunduh file project FLM, melihat progress view tiap video, dan memesan layanan DJ secara langsung. Sistem kunci view dibuat agar video di YouTube ikut terdukung oleh para pengunduh.

Pertanyaan Umum

Apa itu file FLM?

FLM adalah format file project dari FL Studio Mobile. File ini bisa dibuka di aplikasi FL Studio Mobile untuk melihat susunan track dan mengolahnya kembali.

Kenapa tombol download terkunci?

Setiap project punya target view di YouTube, yaitu 500 atau 1K view. Selama jumlah view belum mencapai target, download tetap terkunci. Progress-nya terlihat di halaman download.

Bagaimana cara membuka download?

Buka video project di YouTube lewat tombol "Tonton di YouTube", lalu bantu bagikan. Setelah view mencapai target, buka kembali halaman download dan tombolnya akan aktif.

Bolehkah project dipakai ulang?

Boleh dipakai untuk belajar dan berkreasi. Jika dipublikasikan, mohon cantumkan kredit "Tomy Eka RMX" dan jangan menjual ulang file project.

Bagaimana cara order DJ atau membeli project?

Buka menu Order, pilih layanan, lalu klik tombol pesan. Kamu akan langsung diarahkan ke WhatsApp Business.
